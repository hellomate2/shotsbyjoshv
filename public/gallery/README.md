# Josh — drop your real photos here

1. Save the images you want to feature from your Instagram:
   https://www.instagram.com/shotsbyjosh.v/
2. Place them in this folder (`/public/gallery/`).
3. Open `lib/constants.ts` and update the `GALLERY` array — replace the
   Unsplash URLs with paths like `/gallery/polo-01.jpg` and update the
   `alt` text + `category` for each.

Tip: name files like `polo-01.jpg`, `event-toast-01.jpg`, etc.
The gallery supports `span: "wide"` (2 columns) or `span: "tall"`
(2 rows) on desktop for visual rhythm.
